(B2B flight aggregator, WCF/.NET backend).

## How it slots in

```
flights/page.tsx
  └→ POST /api/v1/search/flights
       └→ services/search.service.ts → buildSearchAdapters() → fanoutSearch()
            ├→ SeriesAdapter   (always — our own contracted inventory)
            ├→ MockAdapter     (non-prod only)
            └→ EtravAdapter    (only if ETRAV_ENABLED=true and ETRAV_* set)
```

The fan-out is `Promise.allSettled` — a slow or failing eTrav doesn't block
the rest of the supplier set. Series + Mock results still flow through.

## Environment

```env
ETRAV_ENABLED=true
ETRAV_BASE_URL=https://stg-api.codemagen.net
ETRAV_USER_ID=tripbng
ETRAV_PASSWORD=...
ETRAV_IP_ADDRESS=<your egress IP — must be whitelisted with eTrav>
ETRAV_IMEI_NUMBER=tripbng-server
ETRAV_TIMEOUT_MS=15000
```

`ETRAV_IP_ADDRESS` is sent in the auth header and **must match an IP
whitelisted with eTrav**. Local dev from a non-whitelisted machine will fail
with auth errors regardless of credential validity. For production, configure
your hosting provider's static egress IP (NAT gateway / fly.io / etc.).

## File map

| File | Purpose |
|---|---|
| `client.ts` | HTTP wrapper + auth header injection + error envelope parsing |
| `types.ts` | Hand-written DTOs that match the wire format (incl. preserved `Applicablility` typo) |
| `transforms.ts` | Pure mappers: dates, baggage strings, `EtravFlight + Fare → NormalizedFareOption` |
| `errors.ts` | `Error_Code` → `SupplierAdapterError` with retryable + user-friendly classification |
| `etrav.adapter.ts` | The class registered with the supplier registry |
